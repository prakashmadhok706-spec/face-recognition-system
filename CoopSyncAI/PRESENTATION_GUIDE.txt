PART 3: THE SOLUTION (What is CoopSync AI?)
================================================================================

Say this:

  "CoopSync AI is a full-stack, AI-powered web application with
   9 integrated modules -- all running together in one dashboard.

   Let me walk you through each module in 60 seconds."

   MODULE 1 -- AI FACE RECOGNITION ATTENDANCE
     - Uses OpenCV + LBPH algorithm to recognize registered students
     - The webcam captures the student's face in real time
     - Anti-spoofing is built in -- it REJECTS photos and phone screens
     - Marks attendance only when a LIVE face is verified
     - Confidence score and timestamp are stored in the database

   MODULE 2 -- DYNAMIC QR ATTENDANCE
     - Instructor generates a QR code on screen
     - The QR expires in exactly 30 SECONDS (like an OTP)
     - The QR has a SHA-256 cryptographic signature
     - If someone tries to share it on WhatsApp -- it will already be expired
     - Each student can scan it ONLY ONCE per session

   MODULE 3 -- STUDENT ERP
     - Complete student profiles with Roll Number, Department, Semester
     - Attendance percentage ring -- shows warning below 75%
     - Skills tags, gender, degree, year
     - Search and filter by name or department

   MODULE 4 -- COOPERATIVE COURSE LMS
     - Course catalog for cooperative training programs
     - Progress tracking with completion percentage bars
     - Trainers/Admins can create new courses from the dashboard

   MODULE 5 -- TAMPER-PROOF DIGITAL CERTIFICATES
     - PDF certificates generated automatically using Python ReportLab
     - Each certificate has a unique ID and embedded QR code
     - ANYONE can scan the QR to verify authenticity online
     - Cannot be forged -- verification checks the live database

   MODULE 6 -- AI EMPLOYMENT PORTAL
     - Live job board from cooperative federations and companies
     - AI matches the student's skills to job requirements
     - Shows a match percentage (e.g., 94% Match)
     - Students can apply with ONE CLICK

   MODULE 7 -- ANALYTICS DASHBOARD
     - Real-time KPI cards: Total Students, Today's Attendance %, Placement Rate
     - Weekly attendance bar chart
     - Department distribution pie chart
     - Export attendance report as CSV

   MODULE 8 -- AI ADVISOR CHATBOT
     - Students ask questions like:
         "How many days have I attended?"
         "Which jobs match my profile?"
         "Recommend a course for me"
     - The chatbot reads REAL data from the database and answers

   MODULE 9 -- OFFLINE SYNC
     - If the internet is down during attendance, data is saved locally
     - As soon as connectivity returns, it auto-syncs to the server
     - No attendance record is EVER lost

PART 5: TECHNICAL ARCHITECTURE (For Judge Questions)
================================================================================

FRONTEND:
  - Framework : React 19 + TypeScript
  - Build Tool: Vite (builds in ~1 second)
  - Port      : localhost:5173
  - Key Files : FaceAttendanceView.tsx, QRAttendanceView.tsx, main.tsx

BACKEND:
  - Framework : FastAPI (Python)
  - Server    : Uvicorn (ASGI)
  - Port      : localhost:8000
  - API Docs  : localhost:8000/docs (auto-generated Swagger)
  - Key Files : main.py, face_engine.py, qr_engine.py, ai_engine.py,
                certificate_engine.py, database.py

DATABASE:
  - ORM       : SQLAlchemy 2.0
  - Dev DB    : SQLite (coopsync.db)
  - Prod DB   : PostgreSQL (via DATABASE_URL env variable)
  - Tables    : users, attendances, courses, certificates, jobs, job_applications

COMPUTER VISION:
  - Library   : OpenCV 4.13
  - Algorithm : LBPH (Local Binary Pattern Histogram)
  - Model     : classifier.xml (pre-trained, ~15MB)
  - Detection : Haar Cascade (haarcascade_frontalface_default.xml)
  - Liveness  : Laplacian Variance > 45.0 = Live Face

QR SYSTEM:
  - Library   : qrcode (Python)
  - Security  : SHA-256 hash + 30-second expiry + one-time-use per student

CERTIFICATES:
  - Library   : ReportLab (Python PDF generation)
  - Format    : A4 PDF with embedded QR verification code

DEPLOYMENT:
  - Docker    : Backend Dockerfile + Frontend Dockerfile
  - Compose   : docker-compose.yml (full stack in one command)
  - Windows   : start_coopsync.bat (1-click launcher)

PART 9: ANSWERS TO TOUGH JUDGE QUESTIONS
================================================================================

Q: "What makes your face recognition better than Aadhaar biometrics?"
A: "Aadhaar uses fingerprint. We use face recognition which requires
    ZERO PHYSICAL CONTACT. It is faster, hygienic, and works at a distance.
    We also add anti-spoofing which Aadhaar kiosks do not always have."

Q: "Can someone fool your system with a photo?"
A: "No. Our Laplacian Variance algorithm measures image texture frequency.
    A printed photo or screen has low texture. A real face has high texture.
    If the variance is below 45, the system rejects it as a spoof attempt."

Q: "What if the internet goes down during attendance?"
A: "The system uses Offline Sync. Attendance is saved in the browser's
    local storage. The moment connectivity restores, it auto-syncs to
    the backend database. No record is lost."

Q: "Why SQLite and not PostgreSQL?"
A: "SQLite is used for development and demos. Our DATABASE_URL environment
    variable can switch to PostgreSQL instantly -- zero code change required.
    The Docker Compose file already has PostgreSQL configured."

Q: "How many students can this system handle?"
A: "Currently we have SQLite optimized for institute-level use (1000+ students).
    For national scale, we switch to PostgreSQL + FAISS vector search +
    GPU-based FaceNet -- the architecture already supports this upgrade."

Q: "Is the AI chatbot using ChatGPT?"
A: "Currently it uses a rule-based semantic engine that reads REAL data from
    our database. It knows each student's actual attendance count and skills.
    We have built the interface to accept an OpenAI or Gemini API key
    as a future enhancement."

Q: "How do you prevent one student from sharing the QR with another?"
A: "Two ways: First, the QR expires in 30 seconds -- too fast to share.
    Second, each student ID can only scan each session ONCE.
    Even if shared, the second student gets 'Already scanned' error."

Q: "What is your confidence threshold for face recognition?"
A: "We reject any prediction with LBPH distance greater than 68.
    This translates to approximately 69% confidence.
    Below this, the system says 'Face Not Recognized' -- the student
    cannot mark themselves present."
